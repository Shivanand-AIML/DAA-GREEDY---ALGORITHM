# DAA - Greedy Algorithm

C solutions for the Greedy Method experiment in Design and Analysis of Algorithms.

## Programs

1. `1-G-Coin-Problem.c` — Minimum number of Indian currency notes/coins.
2. `2-G-Cookies-Problem.c` — Assign cookies to maximize the number of content children.
3. `3-G-Burger-Calories-Problem.c` — Minimize the running distance for burger calories.
4. `4-G-Array-Sum-Max-Problem.c` — Maximize the sum of `arr[i] * i`.
5. `5-G-Minimum-Product-of-Pairs.c` — Minimize the sum of paired products by rearranging two arrays.

## Language
C
